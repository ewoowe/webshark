# WebShark - 后台管理系统版

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问应用
打开浏览器访问：`http://localhost:38081`

## 功能导航

### 📊 仪表盘
- 查看系统统计信息（数据包数量、活跃连接、协议数、流量）
- 快速操作入口（新建抓包、查看数据包、导出数据）
- 最近活动记录追踪

### 🕸️ 抓包分析
- **远程主机连接** - 填写 SSH 连接信息
- **网络接口选择** - 选择要监控的网卡
- **过滤器配置** - 设置 BPF 和 Wireshark 过滤器
- **实时抓包展示** - 虚拟滚动表格，支持大数据量
- **数据包详情** - 点击查看详细信息

### ⚙️ 系统设置
- **界面设置** - 深色模式、自动滚动、声音提示
- **性能设置** - 虚拟滚动阈值、最大数据包数、刷新频率
- **网络设置** - 连接超时、重试次数、心跳间隔
- **关于信息** - 版本信息、技术栈

## 常见问题

### Q: 如何连接远程主机？
A: 在"抓包分析"页面填写主机地址、用户名和密码，然后点击"获取网卡列表"。

### Q: 支持哪些过滤器？
A: 支持 BPF 过滤器（tcpdump 风格）和 Wireshark 过滤器。

### Q: 如何提升大数据量性能？
A: 系统会自动启用虚拟滚动，也可以在"系统设置"中调整性能参数。

### Q: 数据包数量有限制吗？
A: 可以在"系统设置"中设置最大数据包数量，默认为 10000。
